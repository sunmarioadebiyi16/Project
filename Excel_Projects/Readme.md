# Job Posting Analysis Dashboard 📊  

This project explores job postings in the data science field by analyzing **median salaries, required skills, and job counts** across different roles. The results are presented in an interactive **Excel Dashboard**.  

---

## 📌 Project Overview  
The goal of this project was to answer the question:  
**"Do more skills get you better pay?"**  

To explore this, I collected job posting data and built dashboards in Excel that show:  
- Salary distributions across different job titles  
- Number of skills required per job  
- Job counts by type (full-time, contract, internship, etc.)  
- Median salaries by role  

---

## 🔑 Key Insights  
- **Senior roles** (e.g., Senior Data Scientist, Senior Data Engineer) command the highest salaries.  
- **Data Engineer** positions often require more skills compared to other roles.  
- The **median salary for Data Analysts** is among the lowest, at around **$90,000**.  
- While more skills generally correlate with higher pay, exceptions exist (e.g., Senior Data Scientist).
